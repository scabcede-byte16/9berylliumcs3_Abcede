# SG4 - Understanding Classes and Objects
## Sports - Class: Filipino UAAP Women's Volleyball
## My class shows the different games between Filipino UAAP Women's Volleyball.



## Properties
| Property | Data Type | Description |
| Length | int | Length of the game |
| Available | boolean | Checks the availability of the game |
| Points | int | Shows the number of points  |
| Name | string | Shows the names of the two schools currently in a match. |
## Methods
| Method | Description |

| displayLength(Length_of_Game) | Displays the length of the chosen game |
| displayAvailable(Availability_of_game) | Displays if the game is available |
| displayPoints(Amount_of_Points) | Displays the amount of points in a specific game | 
| displayName(Name_of_schools) | Displays the names of the two schools that are in a match |
