# ILA 3-1: Applying the Four Pillars of OOP

## Sari-Sari Store Inventory System

### 1. Encapsulation
Encapsulation can help the sari-sari store by binding the data and methods. This can prevent other parties from messing with the inventory since encapsulation acts as a shield that prevents external code from messing with the item's internal state.

### 2. Abstraction
Abstraction hides the complex code and only shows the essentials. This can help the shopkeeper because they don't have to understand the complex code to use an object or a system.

### 3. Inheritance
Inheritance can have new parties adopt behaviors from parent parties to reuse code. This can prevent duplication of code while stil having different categories.

### 4. Polymorphism
Polymorphism allows objects to use the same method name but different outcomes. This can override a general loop into something more precise.
